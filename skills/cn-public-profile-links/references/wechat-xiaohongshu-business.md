# 重点平台与主体核验

## 优先范围与实际能力

第一优先为本人主动公开的个人微信声明入口与小红书；企查查在明确企业线索出现后用于主体核验。公众号与视频号不是默认查找目标。范围清单与当前可用能力分开：逐次确认有无公开页面、可用站内搜索、用户提供的公开分享页或已连接的正规工具。没有接入能力时报告缺口，不把流程文档写成已经实现的抓取器。

## 微信：默认只记录本人主动公开的个人微信声明入口

从已确认属于本人的公开主页、网站或本人原始声明查找公开联系入口，不靠昵称搜索猜测私人微信。第三方通讯录、转载中的微信号、评论者提供的二维码或同名微信名片不作本人声明。

默认只记录：声明来源页面链接、公开用途（页面明确标注时）、访问日期、声明日期（未知则留空）与“本人声明已读”的状态。不抄录微信号、不复制或导出个人二维码；需要查看联系信息时直接指向本人公开的原始页面。

另外记录发言者与联系角色：本人原文、官方团队说明、第三方转载或评论者；本人个人入口、助手／客服、企业微信或群入口。作者网站是社区时，域名属于本人不代表站内每篇文章和评论都是本人发言，须核对作者链接与署名。助手转述“会提供本人微信”不能替代本人原始声明；企业 AI 服务或客服入口不能记作个人微信。

旧文章公开过入口，可标“历史本人声明已读、当前有效性未知”。原文有活动、对象、用途、会员或时间条件时一并简要记录，不把限时活动转成当前优惠，不建议用户用旧入口绕过当前付费或资格流程；仅有登录／会员中心间接入口时报告访问条件，不付费或添加助手求取私人号码。证据文件和报告均只保存来源与用途，不保存原始微信号或个人二维码。

如果没有可读的本人原始声明，写“未找到本人公开入口”或“声明来源无法读取”，不反查、不通过其他来源补全。不添加好友，不发送验证消息，不测试账号是否可添加，不读取朋友圈、通讯录、群聊或其他私人内容。

这类记录确认的是“本人公开过一个联系入口”，不是当前微信账号所有权、可添加状态或跨平台身份的验证；不计入已核实社交主页数。

联合核验时另查声明来源账号与起始账号的对应关系。公众号确有个人微信声明、小红书确有MCN自述，两条原文都真实可读，也不能代替它们之间的归属证据。分别报告“联系声明内容已读”“声明来源到起始账号的关联状态”；后一段未确认时，不能把入口归入起始账号的已确认资料。MCN创始人自述、旗下签约博主与普通业务合作也须按原文分开，不用一种关系替代另一种。

## 微信：公众号与视频号（仅用户另行指定或作为原始声明来源）

1. 从起始主页或本人网站的“公众号／视频号／关注我”等公开声明、平台名片、本人文章作者区发现入口。区分账号名、平台实际显示的账号标识、文章标题及运营主体。
2. 优先打开本人公开链接的文章、主页或分享卡片，核对作者与账号标识及声明方向。公众号文章中的“作者”署名不一定等于公众号账号本人；转载和团队编辑要分别记录。
3. 公众号与视频号是不同账号类型：即使名称相同或使用同一头像，也不能互相替代。平台主页或资料页实际展示的相互关联可作为证据，记录原文与方向。
4. 本人网站仅展示公众号或视频号名片时，记录名称、可见标识、来源图及声明日期（未知则留空）。未核实目标时使用“有本人声明，目标未核实”，不能通过相同名称自动选中搜索结果。
5. 仅找到文章或公开分享页时，可确认这篇内容的发布账号和可见字段，不宣称完整读取账号资料或历史内容。链接可在微信里打开但工具无法读取时，明确记录渠道限制；不改写成账号不存在。
6. 微信登录、扫码验证由用户处理。公众号管理后台、视频号助手或平台登录入口不是创作者公开主页；不为查公开内容登录创作者管理后台，也不打开与任务无关的私人微信界面。

私人微信与公开创作账号分别处理。不能以同名公众号或视频号替代个人微信入口，也不能因为一个本人公开联系入口就确认其他账号或企业归属。

准确标识须注明平台：公众号ID、小红书号及各平台内部ID属于不同字段，即使字符串相同也不自动互认。转载中标注的公众号ID仍属转载者说明，多站复制不增加独立性。本人仅声明“我的小红书”加昵称时，保留这个声明及其方向，再核对是否能唯一指向已读的准确主页；缺少可检查的映射就保留目标未核实，不补出URL。截图只有通知或平台界面、没有目标昵称／标识时，不把截图当成精确账号证明。

旧帖配图确有准确平台号时，按[旧帖图片中的准确账号标识](evidence-and-report.md#旧帖图片中的准确账号标识)核对本人归属语境、图片与当前主页，分开记录历史声明和当前有效性。

## 小红书

从本人明示链接、公开名片或已核实账号的声明发现候选。记录页面实际显示的昵称、小红书号、主页链接等字段，不把名称、小红书号、URL 内部标识当作同一个字段。

- 同名、相似头像、相同内容不构成账号归属证明；搬运号、品牌号、团队号和个人号分别判断。
- 笔记作者链接可用于定位账号，但别人笔记中的提及、评论或搜索推荐不算本人声明。
- 实际收到的分享链接若包含必要参数，保留原始地址；只记录真实发生的最终跳转，不根据标识生成缺少必要信息的链接，不输出秘密会话凭据。
- 首屏或部分笔记可读、后续需登录时，报告已核实范围。登录页、地域或域名跳转要保留当前渠道的实际状态，不推断账号被删除。
- 普通登录弹窗有正常关闭按钮时可关闭后观察公开区域，不能移除遮罩、修改页面状态或调用隐藏接口。分别记录资料区、笔记卡片、笔记正文和站内搜索的可访问性；标题卡片可见不代表正文可读，卡片实际链接仍回同一主页时不记作已读笔记。

## 企查查：企业主体核验

企查查在本技能中用于核验企业实体，不是个人社交账号搜索器。入口应是目标账号主动披露的公司、工作室正式主体、账号可见的企业认证主体，或确属该主体的官网声明；品牌简称、作品署名或同名自然人不能直接当作企业实体。

用户接受公开签约的境内 MCN 时，也可从创作者或机构明确发布的签约／经纪合作声明取得主体线索。分别核对创作者准确主页、声明中的创作者标识、机构品牌到法律主体全称的对应关系。记录声明人、发布渠道与日期；招聘平台企业简介属于平台承载的机构说明，节目说明不等于已听到的受访者原话。历史名单、网页更新日期与第三方达人榜不能单独证明当前合同仍有效；对外只报告实际读到的公开关系及时间，不能写成个人持股、任职或自有公司。

创作者正文直接提及机构时，可沿实际链接读取机构主页及置顶介绍／问答，优先找明确列名并链接回该创作者的签约声明。感谢、出席活动或机构在评论区祝贺本身不证明签约；同名机构账号的不同内部标识也不自动合并。双向链接确认的是对应页面间的公开关系，合同性质仍须明确文字支持，原文编辑日期不是签约日期或当前有效证明。

可行的证据链示例：

`起始公开账号 → 账号明示的企业全称／企业认证主体 → 企查查具体企业页`

操作要点：

1. 用披露的企业全称或公开企业标识搜索；记录企查查具体企业页及实际显示的企业名称、统一社会信用代码（页面可得时）、相关资料日期。仅有品牌简称时保留待核实，不猜公司全称。
2. 尽可能用全称与统一社会信用代码共同核对。名称存在曾用名或时间差时，须有实际更名信息才能确认是同一企业；一个主体也可能运营多个不同创作者的账号。
3. 分别证明两件事：企业条目是哪家企业，以及起始账号与它是什么公开关系。企业资料匹配并不自动证明某自然人是该企业的法定代表人、员工、股东或账号实际运营者。
4. 摘要仅包含企业主体名称、可见业务简介及已经明确声明的非敏感职业关系。企业资料来自第三方聚合，重要身份结论尽可能回核公司官网或公开登记来源；未回核就注明来源层级与日期。
5. 不以同名自然人搜索拼接公司网，不扩展成个人持股、资产、涉诉、失信或家庭关系画像；不抄录私人联系方式、家庭住址等信息。
6. 只有公开网页可读时就使用公开网页；需登录、权限、付费或应用审核的内容单列缺口。存在 API Key 不代表已获调用付费接口授权；未获既有明确授权不购买、不充值、不调用收费服务。
7. 若当前存在已连接的正规企查查工具，先检查实际工具与字段能力；没有就不声称已经安装 MCP／CLI。第三方社工或泄露数据服务不作为替代。

品牌的 `@账号` 不等于公司全称。记录“创作者自述关联品牌”“品牌账号或网站归属”“店铺披露的运营公司”三段证据，缺一段就保留缺口；店铺链接到同名品牌账号只能支持该店铺的品牌声明，不能自动升级为创作者的工商任职。平台公共页脚的备案公司、建站服务商与店铺自身披露的主体分别判断，不能把平台运营公司归给创作者。

主体线索属于境外司法辖区时先注明范围差异。企查查国内查询与全球企业入口分别记录；入口要求登录而尚未提交公司检索时，写“全球查询入口需登录，未执行主体检索”，不能写“零命中”或“公司不存在”。也不能用其他聚合站的登记编号补成企查查核验。

### 企业核验分层

| 层级 | 记录内容 | 可以怎样报告 |
|---|---|---|
| 本人／公司原始声明 | 创作者明确链接公司官网、官网创始人介绍、隐私政策中的运营公司全称 | 公开声明关系已读；保留声明人与日期，不等于工商任职核实 |
| 企查查站内结果卡 | 精确公司名、实际可见的统一社会信用代码、具体企业链接 | 结果卡字段匹配；注明卡片来源与字段范围，不冒充详情页 |
| 企查查企业详情 | 实际打开详情页读到的对应字段 | 详情页已读／部分可见／需登录；没读到的字段不补齐 |
| 登记或其他原始来源 | 对企业标识及相关字段的独立核对 | 只对实际回核字段写已复核；未访问则标未完成 |

站内结果卡是企查查直接展示的数据，与外部搜索引擎摘要不同；结果卡可读而详情需登录时保留这一组合状态。来自招聘站或其他聚合站的资料必须另标来源，不能冒充企查查数据或用于静默填补缺失字段。

动态榜单的搜索片段、URL 中的日期与实际页面内容可能不同。以实际打开页的内容和数据日期记录观察；找不到片段中的创作者时只保留索引线索，不将其计为当前关系复核。

官网的品牌／团队创立年份、企业登记成立日期、产品上线日期、文章发布时间分别记录。年份不同先检查指向的实体与事件是否相同，不直接认定矛盾，也不编造更名、收购、变更控制等解释。版权年份和网页更新时间不是企业成立日期。

## 报告中的实体类型

| 类型 | 能支持的结论 | 不能自动推出 |
|---|---|---|
| 公众号 | 该发布账号及其可见内容 | 文章署名者拥有该公众号 |
| 视频号 | 该视频号的公开主页与本人声明关系 | 同名公众号与之为同一账号 |
| 小红书账号 | 该主页与起始账号的公开关联证据 | 同名或相似内容就是同一人 |
| 个人微信公开声明 | 本人曾公开提供一个联系入口；仅记录声明页、用途和日期 | 当前可添加、当前所有权、可读取朋友圈或反查实名 |
| 企业主体 | 某账号明示的运营／认证主体信息匹配 | 创作者个人持股、任职或运营其全部账号 |
