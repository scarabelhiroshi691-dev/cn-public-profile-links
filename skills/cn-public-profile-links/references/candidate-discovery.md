# 从少量公开线索主动发现候选

用于公开创作者、公开职业账号及本人授权的账号整理。目标是提高公开候选的发现率，同时防止同名、转载及旧资料被合并成一个人的档案。不是私人联系方式反查或匿名身份调查。

## 记录起点与范围

- 输入可以是准确主页、公开昵称加平台、公开作品名或项目名。先记录用户实际提供了什么，不把检索中后来发现的答案写成初始输入。
- 自选试跑先说明样本与输入，固定后保留失败分支。记录选样时已看过的资料；同一执行者先筛选再试跑属于探索性试跑，不能称盲测或据此计算准确率。
- 只有昵称时尚没有固定的起始账号。发现首个可确认主页后将它记为起始，不把它同时计为新增跨平台关联。项目、机构、团队与个人分别建立实体记录。
- 任务要求小红书为主、境内公司或匿名可读时仍逐项预检；仅验证发现流程的样本不能冒充这些专项条件均通过。

## 发现、核对、再扩展

1. **发现第一批候选**：用准确昵称、作品名或项目名检索公开网页，兼顾原平台、作者网站、项目仓库、出版方、活动主办方和原始访谈。来源中实际的作者链接优先于再写一批搜索词。
2. **有依据地改变查询**：首轮过宽时组合两条已知公开线索，例如昵称加具体作品名；首轮太窄时去掉平台限定。只使用已观察到的公开别名，不自动翻译、拼音化或枚举账号变体；不得猜测主页内部 ID。
3. **读取目标及归属证据**：核对页面主体、标识、作品和外链。搜索结果、第三方介绍能提供发现依据，但不能自动转成本人声明。复制文章、同主题简介及相似头像不构成独立确认。
4. **扩展已确认来源**：可从已确认主页的公开作品、本人项目、明确账号声明或可追溯原始职业介绍继续发现候选。项目仓库贡献者、活动嘉宾、关注推荐及客户名单不自动归为本人账号或关系人。
5. **控制待核实分支**：可以为一个未确认候选寻找其到既有根节点的直接证据；不能使用它新提供的职业、别名、城市或公司继续寻找更多人或账号。只有证据完成后才允许成为下一轮扩展来源。

准确的独特作品相符可以提升核验优先级，但转载或搬运仍可能产生相同作品。缺少明确账号声明时，最多列为可能关联；不能用多个弱线索相加替代明确关系证据。

复核具体文章时，沿该内容实际作者链接取得主页；平台外链中转页的完整 `href` 可用于记录声明目标，未实际跳转就不称最终落地页。多回答页面须锁定目标回答的作者与正文，不把其他答主、获奖名单中的同名提及或推荐作者当成目标账号。

区分关系声明与作品署名：第一人称“我的网站／我的仓库”加实际链接，可支持该发布账号的单向公开声明；“作者：某人”“原创”标签、参考来源或推荐作品只能支持页面所作的署名／引用，不能单独证明发布账号属于原作者。可读的旧文未提到后来建立的网站时，保留已见作品线索与日期，不据此确认或否定当前归属。

区分作者声明与平台界面文案。分发服务广告中的“支持／已同步平台”通用列表、面经中的招聘公司、相关推荐及读者引用不能直接生成本人账号或任职关系；只有具体作者归属、实际账号链接及正文关系声明可进入核验。

平台搜索可能混排同名账号、作品提及及 AI 总结。AI 总结只作待查提示，不作本人或机构声明；沿每条结果实际作者链接核对内部标识，不能把同名笔记都归目标。共享会话本次站内搜索可用时，优先用准确昵称取得真实主页链接；保留此前渠道的登录缺口，但不让旧限制替代当次观察。

昵称任务可在同一次原样输入后切“用户”筛选，分开记录完全同名、大小写变体与相似昵称。用户卡排名、粉丝数和图解等共同主题不能选择唯一归属；多个准确同名主页仍缺明确声明时保留歧义。只查看前几条就注明截取范围，不称已遍历全部结果。搜索URL可能保留平台编码形式，以实际输入框／标题及真实链接为准，不手工修正或猜主页ID。

交付时区分当前范围未找到匹配候选和已找到多个同名但无法选定。用已见、保存、已读数量说明范围。过滤或访问失败单独说明。先复核本轮已读的候选，仍缺区分依据时只问一条公开线索，例如一条公开作品链接或准确的公开账号 ID。对同一未变化的结果避免重复提问；若用户提供新的线索，保留原查询范围与结果。

笔记正文容器可能夹带“猜你想搜”等推荐文本。它们不是作者声明；作者正文、作者链接、评论者及推荐区须分别核对。机构关系优先读取原始签约语境与准确创作者链接，感谢及评论互动不能替代；编辑日期与签约日期分开记录。

## 检索量与停止

开始时设置适合任务的范围。例如一次小试跑可先做最多 8 个不同查询、核对 10 个候选主页、扩展两轮；这只是默认起点，用户要求更广时可调整并说明成本。阅读已出现的直接证据链接优先，不为用完额度制造查询。

按查询目的记录：查询、所用线索与来源、产生的新候选、是否只是旧结果。连续两个针对性查询只返回已看结果或无关内容时停止该分支，转向已出现的可靠链接；明确线索耗尽则交付，不循环重写同义搜索词。不因工具超时就增加人物或平台匹配范围。

平台登录或验证限制按渠道记录。不得换隐藏接口、借用无关账号、绕过验证来补齐。共享浏览器的资料目录复用与站点登录有效分别验证；初次标题或短暂资料区出现后还要观察是否自动跳登录，不能据初次快照声称完整读取。

用户要求用共享 Chrome 复核时，复用既有会话，在新任务标签中打开已取得的准确链接，保留其他任务标签。分别记录：会话／资料目录是否复用、页面是否显示登录状态、实际可读区域，以及该渠道本次是否出现验证码。另一浏览器曾遇验证不代表共享 Chrome 本次也受限；两边记录并存。公开可读但仍显示登录／注册时，不称成功复用了站点登录态。实际出现验证码才交给用户，不预先要求登录或验证，也不代为解决。

共享会话的当前标签可能被其他任务或用户切换；点击可能打开新标签。每次操作后核对目标URL与标题，再读取对应页面，不沿用旧标签序号或元素引用处理另一页。正文链接缺域名、格式损坏时保留原状，不凭已知作者身份修成另一个网址；有其他有效声明时逐条判断，不抹去已取得的独立证据。

## 候选表与报告

每个候选至少记录：

| 字段 | 用途 |
|---|---|
| 编号、实体类型、真实 URL | 去重；没有准确 URL 时留空，不能凭昵称生成 |
| 发现来源、查询或父线索 | 回溯为什么出现这个候选 |
| 发现理由 | 直接链接、第三方指认、独特作品相符或仅同名 |
| 目标读取状态 | 已读、部分可见、仅索引、需登录、失败 |
| 归属／关系状态及证据 | 与目标是否明确关联，和主页是否可读分别记录 |
| 矛盾、时间及缺口 | 包括旧声明、转载、认证缺失及需要什么证据 |
| 是否允许继续扩展 | 仅已确认来源可以，未确认分支只做归属核验 |

报告将**已确认信息**与**未确认候选**分开；有本人声明但目标未读、冲突／排除项各自标明。候选资料只出现在候选表，不进入个人摘要。空结果与访问失败也是可交付结果，不输出身份概率或全网覆盖承诺。

微信沿用重点平台规则：只记录本人主动公开的个人微信声明页、用途和时间；不将公众号、机构客服、节目主持人或助理当成本人个人入口。企业只在明确披露法律主体或用户接受的 MCN 原始声明出现后核验，不以同名自然人补公司关系。候选数量增加不能扩大这些边界。
